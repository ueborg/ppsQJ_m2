# proposed/ — state changes awaiting the human gate

Nothing here is applied. Nothing here is authoritative. Files in this directory
are candidate additions to `research/state/**` that the RESEARCHER merges, after
review, using the single-writer merge step.

Typical contents: `claims/<NEW-ID>.yaml`, `evidence/<NEW-ID>.yaml`,
`sources/<SRC-ID>.yaml`, `disputes/<DISP-ID>.yaml`, `EXPERIMENT_SPEC.yaml`.

A proposal may never be cited as support — not by a later task, and not by
another proposal (Charter Appendix A.2).
