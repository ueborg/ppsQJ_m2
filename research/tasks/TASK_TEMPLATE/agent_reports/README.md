**Preserved unedited.** Do not reconcile these into agreement. Where workers
disagree, the disagreement is the finding, and it becomes a dispute proposal
rather than a resolved consensus (Charter §4.4, Appendix A.5).

The red-team reviewer reads these. It must NOT read the lead's synthesis.
